# llm-experiments

Small, reproducible LLM experiments. Each folder has a hypothesis, method, results, and honest limitations.

## Setup

    python3.10 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt

| Experiment | Question | Status |
|---|---|---|
